# PassTwo

Second-pass inner-motion desk for bedroom producers and AI-music finishers.

Suno and loop DAWs reprint a four-bar phrase until it feels safe. The track never leaves the photocopy. Session players keep the chords and the kick, then move the inner voices on the second pass: a third walks, a violin holds, nylon answers, the upright approaches the next root.

PassTwo seats live chairs on that cut. A is the reprint. B is the developed second pass. Both sit at matched loudness. Export is a WAV and a MIDI file that drop on bar 1 of a DAW session.

This build is free.

## Distinct from the line

| Tool | Job |
| --- | --- |
| TagFour | Four bars after the money chorus, then stop |
| LiftTwo | Two-bar production lift into the hook |
| PreEight | Eight-bar musical pre-chorus climb |
| AfterHook | Eight bars after the hook |
| EndEight | Last eight bars of the record |
| LastHook | Last chorus is not a photocopy of chorus 1 |
| ModEight | Drop contrast by taking things out |
| AnswerEight | Second verse is not a reprint |
| Unravel | Chorus is not a louder verse |
| **PassTwo** | Same four chords, second pass moves inside |

Yesterday's ship was TagFour. PassTwo is not an ending and not a pre-chorus.
